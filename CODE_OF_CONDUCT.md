# Code of Conduct

## Our commitment

We want Kolkata Puja to be a welcoming, respectful and constructive open-source project. Everyone who participates in issues, pull requests, discussions, reviews or other project spaces is expected to help maintain a friendly environment.

## Expected behaviour

- Be respectful and considerate of other contributors.
- Assume good intent and discuss ideas rather than attacking people.
- Give useful, specific and actionable feedback.
- Welcome different levels of technical experience.
- Credit original work, sources and contributors appropriately.
- Keep discussions focused on the project when possible.
- Respect privacy and do not publish someone's personal information without permission.
- When reporting pandal data, locations or images, distinguish verified information from suggestions or uncertainty.

## Unacceptable behaviour

The following is not acceptable:

- Harassment, threats, intimidation or personal attacks.
- Discriminatory or hateful conduct.
- Sexual harassment or unwanted sexual attention.
- Doxxing, stalking or publishing private information.
- Trolling, deliberate disruption or repeated bad-faith participation.
- Impersonation or fraudulent claims about the project or its contributors.
- Submitting malicious code, credentials, malware or intentionally harmful content.
- Repeatedly ignoring project, platform or licensing requirements.

## Project discussions

Please keep issue and pull-request discussions professional. For disagreements, explain the technical or factual reason for your position and be willing to revise it when new evidence appears.

## Enforcement

Project maintainers may remove comments, close discussions, reject contributions, or restrict participation when behaviour violates this Code of Conduct. Serious or repeated violations may be reported through the appropriate GitHub mechanisms.

Enforcement decisions should be based on the conduct involved, not on a contributor's identity, popularity or technical seniority.

## Reporting

If you experience or observe behaviour that violates this Code of Conduct, report it privately to the project maintainers through an appropriate private GitHub communication channel rather than escalating the situation publicly. Include the relevant issue, pull request or discussion reference and a concise description of what happened.

For security vulnerabilities, **do not use public issues or this reporting process**. Follow `SECURITY.md` instead.

## Scope

This Code of Conduct applies to project spaces and interactions where a person is representing or participating in the Kolkata Puja project, including repository discussions, issues, pull requests and project-related communication.

## Attribution

This document is based on common open-source community standards and is adapted for this project. It is intended to support a respectful, practical and inclusive contributor community.
